# RE/UGC plugins for Claude

The official plugin marketplace for [RE/UGC](https://reugc.com), a library of
real creator reaction clips (shocked, laughing, excited and more) used as the
opening hook of TikTok, Reels, Shorts and UGC-style ads.

The `reugc` plugin connects Claude to your RE/UGC account through the RE/UGC
MCP server (`https://reugc.com/mcp`) and adds a skill for editing reaction
clips into finished vertical hook videos with your product footage.

## Install (Claude Code)

```
/plugin marketplace add reugc/reugc-claude-plugin
/plugin install reugc@reugc
```

The first time Claude uses a RE/UGC tool you sign in to RE/UGC and approve
access. You need a RE/UGC account with library access or credits.
